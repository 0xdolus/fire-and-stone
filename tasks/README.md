# Tasks

Optional durable copies of GitHub Issue task packets, kept here for local
reference and history independent of GitHub's UI.

Each task packet should mirror the required issue template fields defined in
`docs/architecture/Repository-GitHub-Setup-V1.md` §5 (Goal, Non-goals,
Acceptance criteria, Risk classification, Dependencies, Architecture
references, Allowed/Forbidden paths, Test plan, Assigned agent, Security
notes).

GitHub Issues remain the authoritative, binding copy for the scope of active
work (source-of-truth rank 2). Files here are a convenience mirror, not a
replacement.

No task packets exist yet at bootstrap time.
